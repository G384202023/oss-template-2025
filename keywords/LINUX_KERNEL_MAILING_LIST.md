# LinuxKernelMailingList

## 説明(200文字)

読み方:リナックスカーネルメーリングリスト(LKML)

Linuxカーネル開発を統括しているメーリングリスト。Linuxカーネルに関する情報交換が目的で、パッチやバグ報告、雑談なども流れている。

１ヶ月で投稿数はおよそ6000〜9000通が流れ、議論が行われたものをまとめたダイジェスト版なるものも発酵されている。

ルールではないが、膨大な投稿数に利用者らが対応できるように、サグジェクトの先頭にその記事の種類をつけるようにするのがマナーとなっているそうだ。
