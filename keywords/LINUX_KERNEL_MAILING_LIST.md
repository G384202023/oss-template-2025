# LinuxKernelMailingList

## 説明(200文字以上)

読み方:リナックスカーネルメーリングリスト(LKML)

Linuxのカーネル開発を統括したメーリングリストのことを指します。

Linuxカーネルの開発はGitではなくメールで行われており、Linuxカーネルに関する情報交換が目的で、パッチやバグ報告、雑談なども流れています。

１ヶ月で投稿数はおよそ6000〜9000通が流れ、議論が行われたものをまとめたダイジェスト版も発行されています。

また、ルールにはなっていませんが、膨大な投稿数に利用者らが対応できるように、宛先の先頭にその記事の種類をつけるようにするのがマナーとなっているそうです。

つまり、Linuxのカーネル開発で知りたい内容について簡単にアクセスでき、その技術者たちのコミュニティの形成も可能になっているそうです。
